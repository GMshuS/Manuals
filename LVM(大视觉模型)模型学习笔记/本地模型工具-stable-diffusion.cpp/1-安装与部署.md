# stable-diffusion.cpp（leejet版）通俗易懂安装+使用
一句话介绍：**纯C/C++写的SD绘图后端，不用装Python、不用装PyTorch，轻量，CPU/N卡/A卡/Mac都能跑，类似llama.cpp，专门本地跑AI画图**。
> 仓库：[https://github.com/leejet/stable-diffusion.cpp](https://github.com/leejet/stable-diffusion.cpp)
> ✅ 新手优先方案：**直接下载编译好的Release包，不要自己源码编译**（编译容易踩坑）

## 一、硬件简单要求
- Windows：N卡推荐CUDA包；AMD显卡下Vulkan包；没有独立显卡就用CPU版本（AVX2/AVX512/noavx）
- Mac：Apple Silicon（M1/M2/M3），选darwin-arm64，Metal加速
- 内存：SD1.5模型至少8G内存；GGUF量化模型会更小；显存越大越快
> ⚠️ 重要：**所有文件夹路径不能有中文、空格**，否则大概率报错。

## 二、安装（Windows示例，最简单方式：直接下预编译包）
1. 打开仓库右侧 **Releases** 页面
   [https://github.com/leejet/stable-diffusion.cpp/releases](https://github.com/leejet/stable-diffusion.cpp/releases)
2. 下载对应压缩包：
   - N卡（NVIDIA显卡）：`sd-master-xxx-bin-win-cuda12-x64.zip`
   - AMD显卡：`sd-master-xxx-bin-win-vulkan-x64.zip`
   - 纯CPU：`sd-master-xxx-bin-win-avx2-x64.zip`（大部分现代CPU用这个）
3. 解压到**全英文路径**，例如 `D:\sdcpp`
4. 下载模型（必须！没有模型不能画图）
> 推荐：SD1.5 GGUF模型（体积小，原生支持sd.cpp），去HuggingFace下载 `v1-5-pruned-emaonly-q4_k_m.gguf`
> 放到解压目录，比如 `D:\sdcpp\models\sd15-q4.gguf`

> 补充：源码编译（不推荐新手，仅给需要的人）
```bash
git clone --recursive [https://github.com/leejet/stable-diffusion.cpp](https://github.com/leejet/stable-diffusion.cpp)
cd stable-diffusion.cpp
mkdir build && cd build
# N卡CUDA版本
cmake .. -DSD_CUDA=ON -DCMAKE_BUILD_TYPE=Release
cmake --build . -j
```

## 三、两种使用方式
### 方式1：命令行 sd-cli.exe（最简单，一键生成图片）
进入解压后的文件夹，在地址栏输入 `cmd` 打开命令行。

最简命令示例（文生图 txt2img）
```bash
sd-cli.exe -m models/sd15-q4.gguf -p "a cute cat, high detail, 8k" -n "ugly, blurry" --steps 25 --cfg-scale 7 -s -1 -o out.png
```

参数解释（一看就懂）
- `-m`：后面写**模型文件路径**
- `-p`：正向提示词，你想要画什么
- `-n`：反向提示词，不想要什么（模糊、畸形、丑）
- `--steps 25`：采样步数，20~30平衡速度画质，越大越慢
- `--cfg-scale 7`：提示词遵循度，一般7~8
- `-s -1`：随机种子，每次不一样；固定数字就是固定画面
- `-o out.png`：输出图片文件名，生成后就在当前文件夹

运行后控制台会滚动进度，跑完当前目录就出现 `out.png`。

### 方式2：网页界面 sd-server.exe（推荐！浏览器可视化操作）
直接启动服务，打开网页操作，不用敲长命令：
```bash
sd-server.exe -m models/sd15-q4.gguf --listen 0.0.0.0:8080
```
启动成功后，浏览器打开：`[http://127.0.0.1:8080](http://127.0.0.1:8080)`
- 网页里输入提示词、调整尺寸、步数、CFG，点生成
- 支持图生图、ControlNet、LoRA（新版本支持）

## 四、常见踩坑（必看）
1. 闪退/报错：**路径有中文！** 全部改成英文文件夹名
2. 速度极慢：没有用GPU版本，下载对应CUDA/Vulkan包
3. 模型加载失败：
   - 优先GGUF模型，原生适配sd.cpp；safetensors/ckpt也支持，但文件更大
4. 内存爆掉：用Q4_K_M量化GGUF模型，降低图片分辨率（比如512x512）

## 五、补充小知识点
- 支持模型：SD1.5、SDXL、Flux、Qwen-Image，部分支持ControlNet、LoRA
- 支持功能：文生图、图生图、图像修复、简单视频生成
- 优势：**没有Python环境依赖，体积小，低配电脑也能跑**
- 劣势：没有A1111那么多插件，更偏向轻量化、后端调用

## 六、快速测试完整流程（Windows）
1. 下载cuda版本zip，解压D:\sdcpp
2. 把sd1.5 q4 gguf模型放到D:\sdcpp\models
3. cmd进入D:\sdcpp，执行sd-server命令
4. 浏览器打开127.0.0.1:8080，输入`a cute cat`，点生成，等待出图
