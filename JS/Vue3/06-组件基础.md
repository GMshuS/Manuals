# 06 - 组件基础

## 组件注册

### 局部注册（推荐）

```vue
<!-- 直接在 SFC 中导入使用 -->
<script setup>
import MyComponent from './MyComponent.vue'
</script>

<template>
  <MyComponent />
</template>
```

### 全局注册（谨慎使用）

```typescript
// main.ts
import { createApp } from 'vue'
import App from './App.vue'
import MyButton from './components/MyButton.vue'

const app = createApp(App)
app.component('MyButton', MyButton)  // 全局注册
app.mount('#app')
```

## Props — 父子组件传值

### 子组件定义 props

```vue
<!-- ChildComp.vue -->
<script setup>
// 方式一：字符串数组（无校验）
defineProps(['title', 'count', 'user'])

// 方式二：对象语法（带类型校验）— 推荐
defineProps({
  title: String,
  count: {
    type: Number,
    required: true,
    default: 0
  },
  user: {
    type: Object,
    default: () => ({ name: 'default' })
  },
  status: {
    type: String,
    validator: (val) => ['active', 'inactive'].includes(val)
  }
})
</script>

<template>
  <h3>{{ title }}</h3>
  <p>{{ count }}</p>
</template>
```

### 父组件传递 props

```vue
<!-- ParentComp.vue -->
<script setup>
import ChildComp from './ChildComp.vue'
import { ref } from 'vue'

const count = ref(10)
</script>

<template>
  <!-- 静态传递 -->
  <ChildComp title="静态标题" />

  <!-- 动态传递 -->
  <ChildComp :title="dynamicTitle" :count="count" />

  <!-- 传递对象所有属性 -->
  <ChildComp v-bind="{ title: '标题', count: 5 }" />
</template>
```

### Props 命名约定

- 子组件定义：驼峰（camelCase）`defineProps(['userName'])`
- 父组件传递：短横线（kebab-case）`:user-name="xxx"`
- 两者均可互转，Vue 会自动处理

### Props 单向数据流

> Props 遵循单向数据流，子组件不应直接修改 props

```vue
<script setup>
const props = defineProps(['count'])

// ❌ 错误：子组件不应直接修改 props
props.count++

// ✅ 正确：将 prop 赋值给局部 ref
const localCount = ref(props.count)

// ✅ 正确：基于 prop 派生计算属性
const doubleCount = computed(() => props.count * 2)
</script>
```

## Emits — 子向父通信

### 子组件触发事件

```vue
<!-- ChildComp.vue -->
<script setup>
// 方式一：字符串数组
const emit = defineEmits(['update', 'delete'])

// 方式二：对象语法（带校验）
const emit = defineEmits({
  update(payload) {
    return typeof payload === 'number'
  },
  delete(id) {
    return id > 0
  }
})

function handleClick() {
  emit('update', 42)
}

function handleDelete() {
  emit('delete', 1)
}
</script>

<template>
  <button @click="handleClick">更新</button>
  <button @click="handleDelete">删除</button>
</template>
```

### 父组件监听事件

```vue
<!-- ParentComp.vue -->
<script setup>
import ChildComp from './ChildComp.vue'

function onUpdate(val) {
  console.log('更新值:', val)
}

function onDelete(id) {
  console.log('删除:', id)
}
</script>

<template>
  <ChildComp @update="onUpdate" @delete="onDelete" />
</template>
```

## v-model 在组件中的应用

### 基本用法 (Vue 3.4+ `defineModel`)

```vue
<!-- ChildComp.vue -->
<script setup>
const model = defineModel()

// 带选项
// const model = defineModel({ required: true, default: '' })
</script>

<template>
  <input v-model="model" />
</template>
```

```vue
<!-- ParentComp.vue -->
<ChildComp v-model="parentValue" />
```

### 多个 v-model

```vue
<!-- ChildComp.vue -->
<script setup>
const name = defineModel('name')
const email = defineModel('email')
</script>

<template>
  <input v-model="name" placeholder="姓名">
  <input v-model="email" placeholder="邮箱">
</template>
```

```vue
<!-- ParentComp.vue -->
<ChildComp v-model:name="userName" v-model:email="userEmail" />
```

### v-model 修饰符

```vue
<script setup>
const [model, modifiers] = defineModel({
  set(value) {
    if (modifiers.capitalize) {
      return value.charAt(0).toUpperCase() + value.slice(1)
    }
    return value
  }
})
</script>
```

```vue
<ChildComp v-model.capitalize="text" />
```

## Slots — 插槽

### 默认插槽

```vue
<!-- Card.vue -->
<template>
  <div class="card">
    <slot />  <!-- 插槽内容在此处渲染 -->
  </div>
</template>

<!-- 使用 -->
<Card>
  <p>插槽内容</p>
</Card>
```

### 具名插槽

```vue
<!-- Layout.vue -->
<template>
  <header><slot name="header" /></header>
  <main><slot /></main>
  <footer><slot name="footer" /></footer>
</template>

<!-- 使用 -->
<Layout>
  <template #header>
    <h1>标题</h1>
  </template>

  <p>默认插槽内容</p>

  <template #footer>
    <p>底部信息</p>
  </template>
</Layout>
```

### 作用域插槽

```vue
<!-- List.vue -->
<script setup>
const items = ref(['A', 'B', 'C'])
</script>

<template>
  <ul>
    <li v-for="(item, index) in items" :key="index">
      <slot :item="item" :index="index" />
    </li>
  </ul>
</template>

<!-- 使用 -->
<List v-slot="{ item, index }">
  <span>{{ index }}. {{ item }}</span>
</List>

<!-- 具名作用域插槽 -->
<List>
  <template #default="{ item }">
    <b>{{ item }}</b>
  </template>
</List>
```

## 递归组件

```vue
<!-- TreeNode.vue -->
<script setup>
defineProps({
  tree: {
    type: Object,
    required: true
  }
})

// 在 SFC 中，组件可通过文件名引用自身
</script>

<template>
  <div class="tree-node">
    <span>{{ tree.label }}</span>
    <TreeNode
      v-for="child in tree.children"
      :key="child.id"
      :tree="child"
    />
  </div>
</template>
```

## 动态组件

```vue
<script setup>
import { shallowRef } from 'vue'
import CompA from './CompA.vue'
import CompB from './CompB.vue'

const current = shallowRef(CompA)
</script>

<template>
  <button @click="current = CompA">A</button>
  <button @click="current = CompB">B</button>

  <component :is="current" />
</template>
```

## 组件命名约定

| 注册方式 | 推荐命名 | 使用方式 |
|---------|---------|---------|
| SFC 导入 | PascalCase | `<MyComponent />` |
| SFC 导入 | PascalCase | `<my-component />` |
| 全局注册 | PascalCase | 两者皆可 |
| DOM 模板内 | 必须 kebab-case | `<my-component>` |
