# 07 - 组件进阶

## Provide / Inject — 依赖注入

用于跨层级传递数据，避免逐层传递 props。

### 提供数据

```vue
<!-- Ancestor.vue -->
<script setup>
import { ref, provide } from 'vue'

const theme = ref('light')
const user = reactive({ name: 'Alice', role: 'admin' })

// 提供值
provide('theme', theme)
provide('user', user)

function toggleTheme() {
  theme.value = theme.value === 'light' ? 'dark' : 'light'
}
</script>

<template>
  <button @click="toggleTheme">切换主题</button>
  <Descendant />
</template>
```

### 注入数据

```vue
<!-- Descendant.vue -->
<script setup>
import { inject } from 'vue'

const theme = inject('theme')
const user = inject('user')

// 提供默认值
const config = inject('config', { debug: false })

// 不可选：注入的值为 undefined 时用默认值
const missing = inject('not-exists', '默认值')
</script>

<template>
  <div :class="theme">
    <p>{{ user.name }} - {{ user.role }}</p>
  </div>
</template>
```

### 使用 Symbol 避免命名冲突

```typescript
// keys.ts
export const THEME_KEY = Symbol('theme')
export const USER_KEY = Symbol('user')
```

```vue
<script setup>
import { THEME_KEY, USER_KEY } from './keys'
import { provide } from 'vue'

provide(THEME_KEY, ref('dark'))
</script>
```

### 响应式注入

```vue
<script setup>
// 子组件中修改注入的值（需谨慎：应让提供方修改）
const theme = inject('theme')

function setDark() {
  theme.value = 'dark'  // 会触发提供方响应式更新
}
</script>
```

### 只读注入

```vue
<script setup>
import { inject, readonly } from 'vue'

const theme = inject('theme')
provide('theme', readonly(theme))  // 注入方不可修改
</script>
```

### 应用程序级别 provide

```typescript
// main.ts
import { createApp } from 'vue'

const app = createApp(App)
app.provide('global', { version: '3.x' })
```

## 动态组件

### `<component :is>`

```vue
<script setup>
import { shallowRef } from 'vue'
import TabHome from './TabHome.vue'
import TabAbout from './TabAbout.vue'
import TabContact from './TabContact.vue'

const tabs = { TabHome, TabAbout, TabContact }
const currentTab = shallowRef(TabHome)
</script>

<template>
  <button v-for="(comp, name) in tabs" :key="name" @click="currentTab = comp">
    {{ name }}
  </button>

  <KeepAlive>
    <component :is="currentTab" />
  </KeepAlive>
</template>
```

### 动态组件传参

```vue
<component :is="currentComp" :prop-a="data" @some-event="handler" />
```

## 异步组件 — defineAsyncComponent

### 基本用法

```vue
<script setup>
import { defineAsyncComponent } from 'vue'

// 基础用法
const AsyncComp = defineAsyncComponent(() =>
  import('./MyComponent.vue')
)

// 完整配置
const AsyncCompWithOptions = defineAsyncComponent({
  loader: () => import('./MyComponent.vue'),
  loadingComponent: LoadingSpinner,  // 加载中显示的组件
  delay: 200,                        // 延迟显示 loading 组件
  errorComponent: ErrorDisplay,      // 加载失败显示的组件
  timeout: 5000,                     // 超时时间
  suspensible: false,                // 是否可被 Suspense 挂起
  onError(error, retry, fail, attempts) {
    if (attempts < 3) {
      retry()  // 重试
    } else {
      fail()
    }
  }
})
</script>

<template>
  <AsyncComp />
  <AsyncCompWithOptions />
</template>
```

### 在路由中使用异步组件

```typescript
// router/index.ts
const routes = [
  {
    path: '/dashboard',
    component: () => import('../views/Dashboard.vue')
  }
]
```

## KeepAlive — 缓存组件状态

### 基本用法

```vue
<template>
  <KeepAlive>
    <component :is="currentView" />
  </KeepAlive>
</template>
```

### 条件缓存

```vue
<template>
  <!-- 只缓存 Home 和 About -->
  <KeepAlive :include="['Home', 'About']">
    <component :is="currentView" />
  </KeepAlive>

  <!-- 排除 Profile -->
  <KeepAlive :exclude="['Profile']">
    <component :is="currentView" />
  </KeepAlive>

  <!-- 最大缓存 10 个实例 -->
  <KeepAlive :max="10">
    <component :is="currentView" />
  </KeepAlive>
</template>
```

### 配合路由

```vue
<template>
  <RouterView v-slot="{ Component }">
    <KeepAlive>
      <component :is="Component" />
    </KeepAlive>
  </RouterView>
</template>
```

### 被缓存组件的生命周期

```vue
<script setup>
import { onActivated, onDeactivated } from 'vue'

onActivated(() => {
  // 从缓存中激活时调用
  console.log('组件被激活')
})

onDeactivated(() => {
  // 切换到其他组件时调用
  console.log('组件被停用')
})
</script>
```

## 模板 ref — 访问子组件实例 / DOM

### 获取 DOM 元素

```vue
<script setup>
import { ref, onMounted } from 'vue'

const inputRef = ref(null)

onMounted(() => {
  inputRef.value?.focus()
})
</script>

<template>
  <input ref="inputRef" />
</template>
```

### 获取子组件实例

```vue
<!-- Parent.vue -->
<script setup>
import { ref, onMounted } from 'vue'
import ChildComp from './ChildComp.vue'

const childRef = ref(null)

onMounted(() => {
  childRef.value?.performAction()
})
</script>

<template>
  <ChildComp ref="childRef" />
</template>
```

```vue
<!-- ChildComp.vue -->
<script setup>
function performAction() {
  console.log('子组件方法被调用')
}

defineExpose({ performAction })
</script>
```

### v-for 中的 ref

```vue
<script setup>
import { ref, onMounted } from 'vue'

const itemRefs = ref([])

onMounted(() => {
  console.log(itemRefs.value.length)  // 3
})
</script>

<template>
  <li v-for="item in 3" :key="item" :ref="el => itemRefs[item - 1] = el">
    {{ item }}
  </li>
</template>
```

## 组件名解析的注意事项

- SFC 中导入组件后可直接在模板中使用
- DOM 内模板（无构建步骤）需使用 kebab-case
- 递归组件在 SFC 中由文件名自动推断
