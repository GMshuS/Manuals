# 08 - 生命周期

Vue3 组件从创建到销毁经历一系列生命周期钩子。

## 组合式 API 钩子

```vue
<script setup>
import {
  onBeforeMount,
  onMounted,
  onBeforeUpdate,
  onUpdated,
  onBeforeUnmount,
  onUnmounted,
  onActivated,
  onDeactivated,
  onErrorCaptured,
  onRenderTracked,
  onRenderTriggered
} from 'vue'

onBeforeMount(() => {
  // DOM 尚未挂载
})

onMounted(() => {
  // DOM 已挂载，可访问 DOM 和发起请求
})

onBeforeUpdate(() => {
  // DOM 即将更新
})

onUpdated(() => {
  // DOM 已更新
})

onBeforeUnmount(() => {
  // 清理定时器、事件监听等
})

onUnmounted(() => {
  // 组件已卸载
})

onActivated(() => {
  // 被 KeepAlive 缓存的组件激活时
})

onDeactivated(() => {
  // 被 KeepAlive 缓存的组件停用时
})

onErrorCaptured((error, instance, info) => {
  // 捕获后代组件的错误
  console.error(error, instance, info)
  return false  // 返回 false 阻止错误继续传播
})

onRenderTracked((event) => {
  // 调试：追踪响应式依赖
})

onRenderTriggered((event) => {
  // 调试：触发重新渲染的依赖
})
</script>
```

## 生命周期流程图

```
创建组件
   ↓
setup() / <script setup>      ← 创建响应式数据、计算属性、侦听器
   ↓
onBeforeMount                  ← 编译模板，准备渲染
   ↓
onMounted                      ← DOM 已挂载
   ↓  ┌──────────────────┐
   │ 数据变化             │
   ↓  ↓                   │
onBeforeUpdate            │  ← DOM 即将更新
   ↓                      │
onUpdated                 │  ← DOM 已更新
   ↓ └──────────────────┘
组件卸载
   ↓
onBeforeUnmount               ← 清理工作
   ↓
onUnmounted                   ← 组件已销毁
```

## 选项式 API 映射

| 选项式 | 组合式 |
|--------|--------|
| `beforeCreate` | `setup()` |
| `created` | `setup()` |
| `beforeMount` | `onBeforeMount` |
| `mounted` | `onMounted` |
| `beforeUpdate` | `onBeforeUpdate` |
| `updated` | `onUpdated` |
| `beforeUnmount` | `onBeforeUnmount` |
| `unmounted` | `onUnmounted` |
| `activated` | `onActivated` |
| `deactivated` | `onDeactivated` |
| `errorCaptured` | `onErrorCaptured` |
| `renderTracked` | `onRenderTracked` |
| `renderTriggered` | `onRenderTriggered` |

> Vue3 移除了 Vue2 的 `beforeCreate` 和 `created`，对应的逻辑直接放在 `setup()` 或 `<script setup>` 顶层即可。

## 各阶段实践指南

### setup — 初始化

```vue
<script setup>
// 初始化响应式数据、computed、watch
const count = ref(0)
const doubled = computed(() => count.value * 2)

// 非异步初始化逻辑
console.log('组件初始化')
</script>
```

### onMounted — DOM 操作 & 请求

```vue
<script setup>
import { ref, onMounted } from 'vue'

const el = ref(null)
const data = ref(null)

onMounted(() => {
  // DOM 元素已可用
  el.value?.focus()

  // 发起数据请求
  fetchData()

  // 绑定第三方库
  initChart(el.value)
})

async function fetchData() {
  const res = await fetch('/api/data')
  data.value = await res.json()
}
</script>

<template>
  <div ref="el"></div>
</template>
```

### onBeforeUnmount — 清理资源

```vue
<script setup>
import { ref, onMounted, onBeforeUnmount } from 'vue'

const intervalId = ref(null)

onMounted(() => {
  intervalId.value = setInterval(() => {
    console.log('tick')
  }, 1000)
})

onBeforeUnmount(() => {
  clearInterval(intervalId.value)  // 清理定时器
  window.removeEventListener('resize', handler)  // 移除事件监听
  dispose()  // 释放第三方资源
})
</script>
```

### Composables 中的生命周期

```typescript
// useEventListener.ts
import { onMounted, onBeforeUnmount } from 'vue'

export function useEventListener(target: EventTarget, event: string, handler: Function) {
  onMounted(() => target.addEventListener(event, handler as any))
  onBeforeUnmount(() => target.removeEventListener(event, handler as any))
}
```

### onErrorCaptured — 错误边界

```vue
<!-- ErrorBoundary.vue -->
<script setup>
import { ref, onErrorCaptured } from 'vue'

const error = ref(null)

onErrorCaptured((err, instance, info) => {
  error.value = err
  console.error('捕获错误:', err, info)
  return false  // 阻止错误向上传播
})
</script>

<template>
  <div v-if="error">
    <h3>出错了</h3>
    <p>{{ error.message }}</p>
  </div>
  <slot v-else />
</template>
```

## 注意事项

- 生命周期钩子必须在 `setup()` 内同步注册
- 不要在 `setup` 中使用 `async`（顶层 await 除外）
- 每个钩子可注册多次，按注册顺序依次执行
- `onBeforeUnmount` 清理的资源需与 `onMounted` 中创建的资源一一对应
