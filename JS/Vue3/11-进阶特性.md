# 11 - 进阶特性

## Teleport — 传送门

将子组件渲染到 DOM 树的任意位置（如 body、模态框外层）。

```vue
<!-- Modal.vue -->
<script setup>
defineProps({ visible: Boolean })
</script>

<template>
  <Teleport to="body">
    <div v-if="visible" class="modal-overlay">
      <div class="modal-content">
        <slot />
      </div>
    </div>
  </Teleport>
</template>

<style scoped>
.modal-overlay { /* 全屏样式 */ }
</style>
```

### Teleport 常用场景

```vue
<template>
  <!-- 模态框传送到 body -->
  <Teleport to="body">
    <Modal />
  </Teleport>

  <!-- 提示传送到指定容器 -->
  <Teleport to="#toast-container">
    <Toast />>
  </Teleport>

  <!-- 条件传送 -->
  <Teleport :to="fullscreen ? 'body' : null">
    <Player />
  </Teleport>

  <!-- 禁用 Teleport（3.3+） -->
  <Teleport to="body" :disabled="!isMobile">
    <Menu />
  </Teleport>
</template>
```

### Teleport 注意事项

- 传送后的元素逻辑上仍属于父组件（props/事件/注入正常）
- 样式作用域（scoped）仍然生效
- 多个 Teleport 共享 to 目标时按顺序追加
- 目标元素必须已存在于 DOM 中

## Suspense — 异步依赖处理

管理组件树中的异步依赖（异步组件、顶层 await）。

```vue
<template>
  <Suspense>
    <!-- 默认内容 -->
    <AsyncComponent />

    <!-- 加载中占位 -->
    <template #fallback>
      <LoadingSpinner />
    </template>
  </Suspense>
</template>
```

### 配合顶层 await

```vue
<!-- AsyncData.vue -->
<script setup>
const res = await fetch('/api/data')
const data = await res.json()

// 此组件会自动暂停，直到异步操作完成
</script>

<template>
  <div v-for="item in data" :key="item.id">{{ item.name }}</div>
</template>
```

### 嵌套 Suspense

```vue
<template>
  <Suspense>
    <main>
      <Suspense>
        <UserProfile />
        <template #fallback><UserSkeleton /></template>
      </Suspense>

      <Suspense>
        <UserPosts />
        <template #fallback><PostSkeleton /></template>
      </Suspense>
    </main>

    <template #fallback>
      <FullPageSkeleton />
    </template>
  </Suspense>
</template>
```

### Suspense 事件

```vue
<script setup>
import { ref } from 'vue'

const onResolve = ref(false)

function handleResolve() {
  onResolve.value = true
}
</script>

<template>
  <Suspense @pending="console.log('pending')" @resolve="handleResolve" @fallback="console.log('show fallback')">
    <AsyncComp />
    <template #fallback><Loading /></template>
  </Suspense>
</template>
```

> Vue3 中 Suspense 仍为**实验性**特性，后续版本可能有 API 变化。

## 自定义指令

### 全局注册

```typescript
// main.ts
import { createApp } from 'vue'

const app = createApp(App)

app.directive('focus', {
  mounted(el) {
    el.focus()
  }
})
```

### 局部注册

```vue
<script setup>
import { ref, vAutoFocus } from './directives'
// 命名规范：vFocus 对应指令名 focus

// 或直接在 <script setup> 中定义
const vFocus = {
  mounted: (el) => el.focus()
}

const vHighlight = {
  mounted: (el, binding) => {
    el.style.backgroundColor = binding.value
  },
  updated: (el, binding) => {
    el.style.backgroundColor = binding.value
  }
}
</script>

<template>
  <input v-focus />
  <p v-highlight="'yellow'">高亮文本</p>
</template>
```

### 指令钩子

```typescript
const myDirective = {
  // 元素挂载前
  created(el, binding, vnode, prevVnode) {},

  // 元素挂载时
  beforeMount() {},

  // 元素已挂载
  mounted(el, binding) {
    // binding.value    - 指令值
    // binding.arg     - 指令参数 (如 v-tooltip:top 中的 'top')
    // binding.modifiers - 修饰符 (如 v-click.outside 中的 { outside: true })
    // binding.oldValue - 旧值（仅在 beforeUpdate / updated 中有值）
  },

  // 组件更新前
  beforeUpdate() {},

  // 组件更新后
  updated() {},

  // 卸载前
  beforeUnmount() {},

  // 已卸载
  unmounted(el) {}
}
```

### 常用指令示例

```typescript
// v-click-outside — 点击外部区域
const vClickOutside = {
  mounted(el, binding) {
    el.__clickOutside = (event: MouseEvent) => {
      if (!el.contains(event.target)) {
        binding.value()
      }
    }
    document.addEventListener('click', el.__clickOutside)
  },
  unmounted(el) {
    document.removeEventListener('click', el.__clickOutside)
  }
}

// v-longpress — 长按
const vLongpress = {
  mounted(el, binding) {
    let timer: number | null = null

    el.__start = () => {
      timer = setTimeout(() => binding.value(), 500)
    }
    el.__end = () => {
      clearTimeout(timer!)
    }

    el.addEventListener('mousedown', el.__start)
    el.addEventListener('mouseup', el.__end)
    el.addEventListener('mouseleave', el.__end)
  },
  unmounted(el) {
    el.removeEventListener('mousedown', el.__start)
    el.removeEventListener('mouseup', el.__end)
    el.removeEventListener('mouseleave', el.__end)
  }
}
```

## 插件

插件通过 `app.use()` 注册，可以添加全局功能。

### 定义插件

```typescript
// plugins/i18n.ts
import type { App } from 'vue'

export default {
  install(app: App, options?: { locale?: string }) {
    // 全局属性
    app.config.globalProperties.$t = (key: string) => {
      return translations[options?.locale || 'zh'][key] || key
    }

    // 全局组件
    app.component('Icon', IconComponent)

    // 全局指令
    app.directive('loading', LoadingDirective)

    // provide
    app.provide('locale', options?.locale || 'zh')

    // 扩展类型
    declare module 'vue' {
      interface ComponentCustomProperties {
        $t: (key: string) => string
      }
    }
  }
}
```

### 使用插件

```typescript
// main.ts
import i18nPlugin from './plugins/i18n'

app.use(i18nPlugin, { locale: 'en' })
```

## 过渡 & 动画

### 单元素/组件过渡

```vue
<template>
  <Transition name="fade">
    <p v-if="show">内容</p>
  </Transition>

  <Transition name="slide">
    <div v-if="show">滑动内容</div>
  </Transition>
</template>

<style>
/* fade 过渡 */
.fade-enter-active,
.fade-leave-active {
  transition: opacity 0.3s ease;
}
.fade-enter-from,
.fade-leave-to {
  opacity: 0;
}

/* slide 过渡 */
.slide-enter-active,
.slide-leave-active {
  transition: transform 0.3s;
}
.slide-enter-from {
  transform: translateX(-100%);
}
.slide-leave-to {
  transform: translateX(100%);
}
</style>
```

### Transition 属性

```vue
<Transition
  name="custom"
  duration="500"
  :css="true"
  @before-enter="onBeforeEnter"
  @enter="onEnter"
  @after-enter="onAfterEnter"
  @enter-cancelled="onEnterCancelled"
  @before-leave="onBeforeLeave"
  @leave="onLeave"
  @after-leave="onAfterLeave"
  @leave-cancelled="onLeaveCancelled"
>
  <div v-if="show">内容</div>
</Transition>
```

### 使用 JavaScript 动画

```vue
<script setup>
function onBeforeEnter(el) {
  el.style.opacity = 0
  el.style.transform = 'scale(0)'
}

function onEnter(el, done) {
  el.animate([
    { opacity: 0, transform: 'scale(0)' },
    { opacity: 1, transform: 'scale(1)' }
  ], {
    duration: 300
  }).finished.then(done)
}

function onLeave(el, done) {
  el.style.opacity = 0
  done()
}
</script>

<Transition
  @before-enter="onBeforeEnter"
  @enter="onEnter"
  @leave="onLeave"
>
  <div v-if="show">内容</div>
</Transition>
```

### 列表过渡 TransitionGroup

```vue
<template>
  <TransitionGroup name="list" tag="ul">
    <li v-for="item in items" :key="item.id">
      {{ item.text }}
      <button @click="remove(item.id)">x</button>
    </li>
  </TransitionGroup>
</template>

<style>
.list-enter-active,
.list-leave-active {
  transition: all 0.3s ease;
}
.list-enter-from,
.list-leave-to {
  opacity: 0;
  transform: translateX(30px);
}
/* 移动动画 */
.list-move {
  transition: transform 0.3s ease;
}
</style>
```

## 渲染函数（h）

直接使用 JavaScript 编写虚拟 DOM。

```vue
<script setup>
import { h } from 'vue'

function renderHeading(props, { slots }) {
  return h(`h${props.level}`, { class: 'heading' }, slots.default())
}
</script>

<template>
  <renderHeading :level="1">主标题</renderHeading>
</template>
```

## 响应式工具函数

| 函数 | 说明 |
|------|------|
| `unref(val)` | `val = isRef(val) ? val.value : val` |
| `toValue(val)` | 3.3+，类似 unref 但也能处理 getter |
| `isRef(val)` | 判断是否为 ref |
| `isReactive(val)` | 判断是否为 reactive |
| `isReadonly(val)` | 判断是否为 readonly |
| `isProxy(val)` | 判断是否为 reactive/readonly 代理 |

```vue
<script setup>
import { ref, unref, toValue } from 'vue'

function useDouble(value: number | Ref<number> | (() => number)) {
  // unref: 接受 ref 或普通值
  const v1 = unref(value)

  // toValue: 接受 ref / 普通值 / getter
  const v2 = toValue(value)
}
</script>
```
