# 01 - 基础与环境搭建

## 环境需求

- Node.js 18+
- 包管理器：npm / yarn / pnpm

## 创建项目

```bash
# 使用 Vite 脚手架
npm create vue@latest

# 或直接在 Vite 中使用 Vue 模板
npm create vite@latest my-app -- --template vue
npm create vite@latest my-app -- --template vue-ts

# 进入目录并安装
cd my-app
npm install
npm run dev
```

## 项目结构

```
my-app/
├── index.html              # 入口 HTML
├── vite.config.ts          # Vite 配置
├── src/
│   ├── main.ts             # 应用入口
│   ├── App.vue             # 根组件
│   ├── components/         # 组件目录
│   └── assets/             # 静态资源
└── package.json
```

## createApp — 创建 Vue 应用

```typescript
// src/main.ts
import { createApp } from 'vue'
import App from './App.vue'

const app = createApp(App)
app.mount('#app')
```

## 单文件组件 (SFC) 结构

```vue
<script setup>
// 组合式 API 脚本
import { ref } from 'vue'

const count = ref(0)
</script>

<template>
  <div class="container">
    <p>{{ count }}</p>
    <button @click="count++">+1</button>
  </div>
</template>

<style scoped>
.container {
  text-align: center;
}
</style>
```

## 模板语法 — 插值

```vue
<script setup>
const msg = 'Hello Vue3'
const html = '<b>富文本</b>'
const num = 42
const flag = true
const user = { name: 'Alice', age: 25 }
</script>

<template>
  <!-- 文本插值 -->
  <p>{{ msg }}</p>

  <!-- 原始 HTML -->
  <p v-html="html"></p>

  <!-- 表达式 -->
  <p>{{ num + 1 }}</p>
  <p>{{ flag ? 'yes' : 'no' }}</p>
  <p>{{ user.name.toUpperCase() }}</p>

  <!-- 属性绑定 -->
  <img :src="user.avatar" :alt="user.name">
  <button :disabled="!flag">提交</button>

  <!-- 动态属性名 -->
  <div :[attrName]="value"></div>
</template>
```

## 指令缩写

| 指令 | 完整写法 | 缩写 |
|------|---------|------|
| v-bind | `v-bind:href` | `:href` |
| v-on | `v-on:click` | `@click` |
| v-slot | `v-slot:default` | `#default` |

## 模板中可用的全局对象

```vue
<template>
  <p>{{ Math.max(1, 2) }}</p>
  <p>{{ Date.now() }}</p>
  <p>{{ JSON.stringify(data) }}</p>
</template>
```

## 样式绑定

```vue
<script setup>
const active = ref(true)
const styleObj = { color: 'red', fontSize: '14px' }
const classObj = { active: true, disabled: false }
const classArr = ['btn', 'btn-primary']
</script>

<template>
  <!-- class 绑定 -->
  <div :class="classObj">对象语法</div>
  <div :class="classArr">数组语法</div>
  <div :class="[active ? 'active' : '', 'base']">条件</div>

  <!-- style 绑定 -->
  <div :style="styleObj">对象语法</div>
  <div :style="[baseStyle, overrideStyle]">数组语法</div>
</template>
```

## 注意事项

- `{{ }}` 内只能写 **表达式**，不能写语句（如 `if` / `for`）
- 插值表达式支持链式调用、三元运算、方法调用
- 模板表达式中的 `this` 不指向组件实例
- `v-html` 会覆盖子元素，且不能与 `{{ }}` 混用
