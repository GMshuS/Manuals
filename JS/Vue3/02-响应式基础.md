# 02 - 响应式基础

Vue3 响应式系统基于 JavaScript Proxy 实现。所有响应式 API 均从 `vue` 导入。

## ref — 基本响应式

`ref` 用于包装**任意值**（基本类型或对象），返回一个带有 `.value` 的响应式引用。

```vue
<script setup>
import { ref } from 'vue'

const count = ref(0)
const name = ref('Alice')
const user = ref({ name: 'Bob', age: 30 })

function increment() {
  count.value++         // 必须通过 .value 读写
  user.value.age++      // 对象内部自动解包
}
</script>

<template>
  <p>{{ count }}</p>       <!-- 模板中自动解包，无需 .value -->
  <p>{{ user.name }}</p>
  <button @click="increment">+1</button>
</template>
```

### ref 的响应式原理

```typescript
// 近似实现
function ref<T>(value: T): Ref<T> {
  return {
    get value() { /* 收集依赖 */ return value },
    set value(newVal) { /* 触发更新 */ value = newVal }
  }
}
```

## reactive — 对象响应式

`reactive` 仅接受**对象类型**（object / array / Map / Set），返回一个深层的响应式代理。

```vue
<script setup>
import { reactive } from 'vue'

const state = reactive({
  count: 0,
  user: { name: 'Alice', hobbies: ['reading'] }
})

function update() {
  state.count++
  state.user.name = 'Bob'
  state.user.hobbies.push('coding')  // 深层响应
}
</script>

<template>
  <p>{{ state.count }}</p>
  <p>{{ state.user.name }}</p>
</template>
```

### reactive 的限制

| 限制 | 说明 |
|------|------|
| 仅对象类型 | 不能用于 string / number / boolean |
| 不可替换引用 | 整个替换 `state = reactive({...})` 会丢失响应 |
| 解构丢失响应 | `const { count } = state` — count 变为普通值 |

## ref  vs  reactive  对比

| 特性 | ref | reactive |
|------|-----|----------|
| 支持类型 | 任意类型 | 仅对象类型 |
| 读写方式 | `.value` | 直接访问 |
| 模板解包 | 自动解包（顶层属性） | 自动解包 |
| 响应式丢失 | 解构/传递不会丢失 | 解构/传递会丢失 |
| 使用推荐 | **首选**，通用性强 | 配合 ref 使用 |

## toRef / toRefs — 保持响应式

保持 `reactive` 对象解构后的响应性。

```vue
<script setup>
import { reactive, toRef, toRefs } from 'vue'

const state = reactive({
  name: 'Alice',
  age: 25
})

// toRef: 单个属性
const nameRef = toRef(state, 'name')
nameRef.value = 'Bob'   // 同时修改 state.name

// toRefs: 所有属性
const { name, age } = toRefs(state)
name.value = 'Charlie'  // 同时修改 state.name
</script>
```

## shallowRef / shallowReactive — 浅层响应式

只追踪顶层属性变化，不进行深层代理，适合大数据结构优化性能。

```vue
<script setup>
import { shallowRef, shallowReactive } from 'vue'

// 只追踪 .value 变化，不追踪内部属性
const arr = shallowRef([1, 2, 3])
arr.value = [4, 5, 6]    // 触发更新
arr.value.push(7)         // 不触发更新！

// 只追踪顶层属性
const state = shallowReactive({
  user: { name: 'Alice' }
})
state.user = { name: 'Bob' }    // 触发更新
state.user.name = 'Charlie'     // 不触发更新！
</script>
```

## readonly — 只读代理

```vue
<script setup>
import { reactive, readonly } from 'vue'

const original = reactive({ count: 0 })
const copy = readonly(original)

original.count++   // OK
copy.count++       // 警告: 只读不可修改
</script>
```

## isRef / isReactive / isProxy — 类型判断

```typescript
import { ref, reactive, isRef, isReactive, isProxy } from 'vue'

const r = ref(0)
const s = reactive({})

isRef(r)       // true
isReactive(s)  // true
isProxy(s)     // true
```

## 在选项式 API 中使用

```vue
<script>
import { ref, reactive } from 'vue'

export default {
  setup() {
    const count = ref(0)
    const state = reactive({ msg: 'hello' })

    function increment() { count.value++ }

    return { count, state, increment }
  }
}
</script>
```

## 最佳实践

- **优先使用 `ref`**，单一职责、便于传递、TS 类型更友好
- 需要管理**多个相关状态**时用 `reactive` + `toRefs`
- 大量数据、**不需要深层响应**时用 `shallowRef`
- 永远不要直接替换 `reactive` 对象的引用
