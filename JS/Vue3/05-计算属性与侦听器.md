# 05 - 计算属性与侦听器

## computed — 计算属性

基于响应式依赖自动计算的派生值，**缓存**直到依赖变化。

### 只读计算属性

```vue
<script setup>
import { ref, computed } from 'vue'

const firstName = ref('张')
const lastName = ref('三')

const fullName = computed(() => {
  return firstName.value + ' ' + lastName.value
})
</script>

<template>
  <input v-model="firstName">
  <input v-model="lastName">
  <p>{{ fullName }}</p>
</template>
```

### 可写计算属性

```vue
<script setup>
const firstName = ref('张')
const lastName = ref('三')

const fullName = computed({
  get() {
    return firstName.value + ' ' + lastName.value
  },
  set(newVal) {
    ;[firstName.value, lastName.value] = newVal.split(' ')
  }
})

function changeName() {
  fullName.value = '李 四'  // 触发 set
}
</script>
```

### 计算属性的缓存特性

```vue
<script setup>
const numbers = ref([1, 2, 3, 4, 5])

// ✅ computed — 缓存，仅依赖变化时重新计算
const evenNumbers = computed(() =>
  numbers.value.filter(n => n % 2 === 0)
)

// ❌ 方法 — 每次渲染都重新计算
function getEvenNumbers() {
  return numbers.value.filter(n => n % 2 === 0)
}
</script>
```

### 计算属性中不要做副作用

```vue
<script setup>
// ❌ 错误：计算属性中修改响应式状态
const bad = computed(() => {
  count.value++                // 副作用！
  return some.value * 2
})

// ✅ 正确：计算属性只做纯计算
const good = computed(() => {
  return some.value * 2
})
</script>
```

## watch — 侦听器

监听响应式数据变化并执行副作用。

### 基本用法

```vue
<script setup>
import { ref, watch } from 'vue'

const count = ref(0)
const name = ref('')
const user = ref({ age: 25 })

// 侦听单个 ref
watch(count, (newVal, oldVal) => {
  console.log(`count: ${oldVal} → ${newVal}`)
})

// 侦听 getter 函数
watch(() => user.value.age, (newAge, oldAge) => {
  console.log(`年龄: ${oldAge} → ${newAge}`)
})
</script>

<template>
  <button @click="count++">{{ count }}</button>
</template>
```

### 侦听多个源

```vue
<script setup>
const x = ref(0)
const y = ref(0)

watch([x, y], ([newX, newY], [oldX, oldY]) => {
  console.log(`x: ${oldX}→${newX}, y: ${oldY}→${newY}`)
})
</script>
```

### deep — 深层侦听

```vue
<script setup>
const obj = ref({ nested: { count: 0 } })

// 默认 watch 不追踪深层变化
watch(obj, (newVal) => {
  // ❌ obj.value.nested.count 变化时不会触发
})

// deep: true 追踪所有深层变化
watch(obj, (newVal) => {
  console.log('深层变化', newVal.nested.count)
}, { deep: true })
</script>
```

### immediate — 立即执行

```vue
<script setup>
const search = ref('')

watch(search, (val) => {
  fetchResults(val)
}, { immediate: true })
// 立即执行一次 fetchResults('')
</script>
```

### flush — 执行时机

```vue
watch(source, callback, {
  flush: 'pre'    // 默认：DOM 更新前执行
  flush: 'post'  // DOM 更新后执行
  flush: 'sync'  // 同步执行
})
```

### 停止侦听

```vue
<script setup>
const count = ref(0)
const unwatch = watch(count, (val) => {
  console.log(val)
})

function stop() {
  unwatch()  // 手动停止侦听
}
</script>
```

## watchEffect — 自动追踪

自动追踪回调中使用到的所有响应式依赖，无需显式声明。

```vue
<script setup>
import { ref, watchEffect } from 'vue'

const userId = ref(1)
const data = ref(null)

watchEffect(async () => {
  // 自动追踪 userId.value
  const res = await fetch(`/api/users/${userId.value}`)
  data.value = await res.json()
})

setTimeout(() => {
  userId.value = 2   // 触发 watchEffect 重新执行
}, 1000)
</script>
```

### watchEffect 的清理

```vue
<script setup>
watchEffect((onCleanup) => {
  const timer = setInterval(() => {
    console.log('tick')
  }, 1000)

  onCleanup(() => {
    clearInterval(timer)  // 组件卸载或重新执行前清理
  })
})
</script>
```

### watchPostEffect / watchSyncEffect

```vue
<script setup>
import { watchPostEffect, watchSyncEffect } from 'vue'

// flush: 'post' 的简写
watchPostEffect(() => {
  // DOM 更新后执行
})

// flush: 'sync' 的简写
watchSyncEffect(() => {
  // 同步执行
})
</script>
```

## computed vs watch vs watchEffect

| 特性 | computed | watch | watchEffect |
|------|----------|-------|-------------|
| 用途 | 派生值 | 副作用 | 副作用 |
| 返回值 | 响应式值 | 无 | 无 |
| 缓存 | 是 | 否 | 否 |
| 懒执行 | 是 | 默认是（可 immediate） | 否 |
| 依赖声明 | 自动 | 显式 | 自动 |
| 异步支持 | 不可 | 可 | 可 |
| 访问旧值 | 不可 | 可 | 不可 |

### 选择建议

```vue
<script setup>
// 需要派生值 → computed
const fullName = computed(() => first.value + last.value)

// 需要在变化时做异步操作 → watch
watch(search, async (val) => {
  data.value = await fetchResults(val)
})

// 需要自动追踪多个依赖 → watchEffect
watchEffect(() => {
  localStorage.setItem('draft', JSON.stringify(draft.value))
})
</script>
```

## 使用技巧

### watch 侦听 reactive

```vue
<script setup>
const state = reactive({ count: 0, name: 'Alice' })

// 侦听整个 reactive
watch(state, (newVal) => { /* ... */ }, { deep: true })

// 侦听单个属性（使用 getter）
watch(() => state.count, (val) => { /* ... */ })
</script>
```

### 侦听 ref 的 .value

```vue
<script setup>
const count = ref(0)

// ✅ 直接传 ref
watch(count, (val) => { /* ... */ })

// 等价于 getter 写法
watch(() => count.value, (val) => { /* ... */ })
</script>
```

### 一次性侦听

```vue
<script setup>
watch(source, (val) => {
  // 仅触发一次
}, { once: true })
</script>
```
