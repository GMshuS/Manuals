# 04 - 模板指令详解

Vue 指令是以 `v-` 前缀的特殊 HTML 属性，用于在模板中执行响应式逻辑。

## 指令总览

| 指令 | 缩写 | 用途 |
|------|------|------|
| `v-bind` | `:` | 动态绑定属性 |
| `v-if` / `v-else-if` / `v-else` | - | 条件渲染 |
| `v-show` | - | 条件显示（切换 display） |
| `v-for` | - | 列表渲染 |
| `v-on` | `@` | 事件绑定 |
| `v-model` | - | 表单双向绑定 |
| `v-html` | - | 输出原始 HTML |
| `v-text` | - | 输出纯文本 |
| `v-once` | - | 只渲染一次 |
| `v-pre` | - | 跳过编译 |
| `v-cloak` | - | 编译前隐藏 |
| `v-memo` | - | 条件缓存（3.2+） |

## v-bind — 动态绑定

```vue
<script setup>
const url = 'https://example.com'
const isDisabled = true
const dynamicAttr = 'data-id'
const objAttrs = { id: 'app', class: 'container' }
</script>

<template>
  <!-- 基本绑定 -->
  <a :href="url">链接</a>

  <!-- 布尔属性 -->
  <button :disabled="isDisabled">提交</button>

  <!-- 动态属性名 -->
  <div :[dynamicAttr]="'value'"></div>

  <!-- 绑定对象 -->
  <div v-bind="objAttrs"></div>

  <!-- 缩写 -->
  <img :src="url" :alt="'描述'">
</template>
```

## v-if / v-else-if / v-else — 条件渲染

```vue
<script setup>
const type = ref('A')
const show = ref(true)
</script>

<template>
  <div v-if="type === 'A'">类型 A</div>
  <div v-else-if="type === 'B'">类型 B</div>
  <div v-else>其他类型</div>

  <!-- v-if + template 分组 -->
  <template v-if="show">
    <h1>标题</h1>
    <p>段落</p>
  </template>
</template>
```

### v-if vs v-show

| 特性 | v-if | v-show |
|------|------|--------|
| 渲染 | 条件为 true 时才渲染 | 始终渲染 |
| 切换 | 销毁/重建 DOM | 切换 display |
| 开销 | 切换开销大 | 初始渲染开销大 |
| 适用 | 运行时切换少的场景 | 频繁切换的场景 |

## v-for — 列表渲染

```vue
<script setup>
const items = ref(['苹果', '香蕉', '橘子'])
const users = ref([
  { id: 1, name: 'Alice' },
  { id: 2, name: 'Bob' }
])
</script>

<template>
  <!-- 遍历数组 -->
  <ul>
    <li v-for="(item, index) in items" :key="index">{{ index }} - {{ item }}</li>
  </ul>

  <!-- 遍历对象 -->
  <div v-for="(value, key, index) in { a: 1, b: 2 }" :key="key">
    {{ index }}. {{ key }}: {{ value }}
  </div>

  <!-- 遍历数字范围 -->
  <span v-for="n in 10" :key="n">{{ n }}</span>

  <!-- v-for + template 分组 -->
  <template v-for="user in users" :key="user.id">
    <h3>{{ user.name }}</h3>
    <p>ID: {{ user.id }}</p>
  </template>
</template>
```

### `:key` 的重要性

- 必须提供唯一的 `:key`，帮助 Vue 高效复用/重排元素
- 优先使用唯一 ID 而非 `index`
- 没有 `:key` 时 Vue 会使用"就地复用"策略，可能导致状态错乱

### v-for 与 v-if 的优先级

> Vue3 中 `v-if` 的优先级高于 `v-for`（Vue2 中相反）

```vue
<!-- Vue3: v-if 优先，无法访问 item -->
<!-- ❌ 错误：v-if 中 item 未定义 -->
<li v-for="item in items" v-if="item.active" :key="item.id">

<!-- ✅ 正确：使用 template 包装 -->
<template v-for="item in items" :key="item.id">
  <li v-if="item.active">{{ item.name }}</li>
</template>

<!-- ✅ 推荐：使用 computed 过滤 -->
<script setup>
const activeItems = computed(() => items.value.filter(i => i.active))
</script>
```

## v-on — 事件绑定

```vue
<script setup>
const count = ref(0)

function greet(msg, event) {
  alert(msg)
}

function handleKeydown(e) {
  if (e.key === 'Enter') { /* ... */ }
}
</script>

<template>
  <!-- 基本用法 -->
  <button @click="count++">+1</button>
  <button @click="greet('hello', $event)">带参数</button>

  <!-- 事件修饰符 -->
  <form @submit.prevent="onSubmit">阻止默认行为</form>
  <a @click.stop="onClick">阻止冒泡</a>
  <div @click.once="doOnce">只触发一次</div>
  <input @keyup.enter="submit">键盘修饰符
  <button @click.ctrl="onCtrlClick">Ctrl + 点击</button>

  <!-- 多事件处理 -->
  <button @click="first(); second()">多个处理器</button>
</template>
```

### 事件修饰符

| 修饰符 | 说明 |
|--------|------|
| `.stop` | `event.stopPropagation()` |
| `.prevent` | `event.preventDefault()` |
| `.capture` | 使用捕获模式 |
| `.self` | 仅 event.target 为自身时触发 |
| `.once` | 只触发一次 |
| `.passive` | 不调用 preventDefault（滚动性能优化） |

### 按键修饰符

`.enter` `.tab` `.delete` `.esc` `.space` `.up` `.down` `.left` `.right`
`.ctrl` `.alt` `.shift` `.meta` `.exact`（精确组合）

## v-model — 表单双向绑定

```vue
<script setup>
const text = ref('')
const checked = ref(false)
const selected = ref('A')
const multiSelected = ref([])
</script>

<template>
  <!-- 文本输入 -->
  <input v-model="text">

  <!-- 多行文本 -->
  <textarea v-model="text"></textarea>

  <!-- 复选框 -->
  <input type="checkbox" v-model="checked">

  <!-- 单选 -->
  <input type="radio" value="A" v-model="selected">
  <input type="radio" value="B" v-model="selected">

  <!-- 选择框 -->
  <select v-model="selected">
    <option value="A">A</option>
    <option value="B">B</option>
  </select>

  <!-- 多选 -->
  <select v-model="multiSelected" multiple>
    <option value="A">A</option>
    <option value="B">B</option>
  </select>
</template>
```

### v-model 修饰符

```vue
<input v-model.trim="text">           <!-- 去除首尾空格 -->
<input v-model.number="age">          <!-- 转为数字 -->
<input v-model.lazy="text">           <!-- 在 change 时而非 input 时同步 -->
```

### v-model 原理

```vue
<!-- 等价于 -->
<input :value="text" @input="text = $event.target.value">
<!-- checkbox: :checked + @change -->
<!-- select: :value + @change -->
```

### 组件上的 v-model

```vue
<!-- 父组件 -->
<ChildComp v-model="name" />

<!-- 子组件 (Vue 3.4+) -->
<script setup>
const model = defineModel()
</script>

<template>
  <input v-model="model">
</template>
```

## v-html — 原始 HTML

```vue
<script setup>
const rawHtml = '<b>加粗</b><script>alert(1)</script>'
</script>

<template>
  <!-- XSS 风险：不要渲染用户输入的内容 -->
  <div v-html="rawHtml"></div>
</template>
```

## v-once / v-pre / v-cloak / v-memo

```vue
<template>
  <!-- v-once: 只渲染一次，后续更新不重新渲染 -->
  <div v-once>{{ expensiveComputation }}</div>

  <!-- v-pre: 跳过编译，直接输出原始内容 -->
  <div v-pre>{{ 这个不会被编译 }}</div>

  <!-- v-cloak: 编译前隐藏，需配合 CSS -->
  <div v-cloak>{{ message }}</div>

  <!-- v-memo: 依赖不变时跳过更新 (3.2+) -->
  <div v-memo="[item.id, item.updated]">
    {{ item.content }}
  </div>
</template>
```

```css
[v-cloak] {
  display: none;
}
```
