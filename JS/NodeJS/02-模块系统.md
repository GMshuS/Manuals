# Node.js 模块系统

Node.js 支持两种模块系统：**CommonJS**（默认）和 **ES Modules**。

---

## CommonJS (CJS)

每个文件是一个独立模块，通过 `require` 导入、`module.exports` 导出。

### 导出

```javascript
// 方式一：挂载到 exports 对象
exports.name = 'Alice'
exports.greet = function () {
  return `Hello, ${exports.name}`
}

// 方式二：使用 module.exports（推荐）
module.exports = {
  name: 'Alice',
  greet() {
    return `Hello, ${this.name}`
  }
}

// 注意：直接给 exports 赋值会断开引用
exports = {} // 错误！不会生效
module.exports = {} // 正确
```

### 导入

```javascript
// 导入核心模块
const fs = require('fs')

// 导入本地模块
const utils = require('./utils')
const utils = require('./utils/index.js')

// 导入第三方模块
const lodash = require('lodash')

// 解构导入
const { readFile, writeFile } = require('fs')

// 导入 JSON
const data = require('./data.json')
```

### 模块查找规则

```
require('./foo')  →  ./foo.js  →  ./foo.json  →  ./foo/index.js
require('bar')    →  node_modules/bar
require('fs')     →  核心模块
```

### 模块包装

Node.js 将每个模块包装在函数中：

```javascript
(function (exports, require, module, __filename, __dirname) {
  // 你的模块代码
})
```

所以 `__filename`、`__dirname` 本质是函数参数，并非真正全局变量。

## ES Modules (ESM)

Node.js 从 v12 开始支持 ES Modules。

### 启用方式

**方式一：** 文件扩展名使用 `.mjs`

**方式二：** `package.json` 中设置 `"type": "module"`

```json
{
  "type": "module"
}
```

`.cjs` 扩展名强制使用 CommonJS，不受 `type` 字段影响。

### 导出

```javascript
// 命名导出
export const name = 'Alice'
export function greet() {}
export class Person {}

// 默认导出
export default function () {}

// 重命名导出
export { name as username }

// 聚合导出
export * from './utils.js'
export { default } from './utils.js'
```

### 导入

```javascript
// 命名导入
import { readFile } from 'fs'
import { name, greet } from './utils.js'

// 默认导入
import utils from './utils.js'

// 混合导入
import React, { useState } from 'react'

// 动态导入（返回 Promise）
const module = await import('./utils.js')

// 全部导入为命名空间
import * as utils from './utils.js'

// 导入 JSON（需要 flags）
import data from './data.json' assert { type: 'json' }
```

### ESM 与 CJS 差异

| 特性 | CommonJS | ES Modules |
|------|----------|------------|
| 导入语法 | `require()` | `import` |
| 导出语法 | `module.exports` / `exports` | `export` / `export default` |
| 加载时机 | 运行时同步加载 | 编译时静态分析 |
| 动态导入 | 天然支持 | `import()` |
| 顶层 await | 不支持 | 支持 |
| `__dirname` | 有 | 无（用 `import.meta.url`） |
| 严格模式 | 需手动开启 | 默认严格模式 |

### ESM 中的 `__dirname` 替代

```javascript
import { fileURLToPath } from 'url'
import { dirname } from 'path'

const __filename = fileURLToPath(import.meta.url)
const __dirname = dirname(__filename)
```

## require 与 import 混用

- 在 ESM 中可以用 `import()` 加载 CJS 模块
- 在 CJS 中不能用 `require()` 加载 ESM 模块（需用动态 `import()`）

```javascript
// CJS 中加载 ESM（异步）
async function loadEsm() {
  const esm = await import('./esm-module.mjs')
}
```
