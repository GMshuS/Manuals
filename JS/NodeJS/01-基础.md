# Node.js 基础

## 什么是 Node.js

Node.js 是一个基于 Chrome V8 引擎的 JavaScript 运行时环境，使 JS 可以脱离浏览器在服务端运行。

**核心特性：**
- 事件驱动 (Event-Driven)
- 非阻塞 I/O (Non-blocking I/O)
- 单线程 + 事件循环 (Event Loop)

## 安装与版本管理

### 安装方式

```bash
# 官网下载安装包
https://nodejs.org/

# 使用 nvm (推荐)
nvm install 20          # 安装 Node 20.x
nvm use 20              # 切换版本
nvm alias default 20    # 设为默认
```

### 验证安装

```bash
node -v    # v20.12.0
npm -v     # 10.5.0
```

## REPL 交互环境

终端输入 `node` 进入 REPL：

```bash
$ node
> 1 + 2
3
> const x = 10
undefined
> x * 2
20
> .exit
```

常用 REPL 命令：

| 命令 | 作用 |
|------|------|
| `.exit` | 退出 |
| `.help` | 帮助 |
| `.clear` | 清除上下文 |
| `.save` | 保存当前会话 |
| `.load` | 加载文件 |

## 运行脚本

```bash
node app.js              # 运行文件
node --watch app.js      # 监听模式 (Node 18+)
node -e "console.log(1)" # 直接执行代码字符串
```

## 全局对象

Node.js 中的全局对象/变量：

```javascript
// global - 顶层对象（类似浏览器的 window）
global.console.log('hello')

// __dirname - 当前模块目录的绝对路径
// __filename - 当前模块文件的绝对路径
console.log(__dirname)   // /Users/me/project
console.log(__filename)  // /Users/me/project/app.js

// process - 当前进程信息
process.argv             // 命令行参数数组
process.cwd()            // 当前工作目录
process.env              // 环境变量
process.exit(0)          // 退出进程

// Buffer - 处理二进制数据
Buffer.from('hello')

// setTimeout/setInterval - 定时器
setTimeout(() => {}, 1000)
setInterval(() => {}, 1000)
setImmediate(() => {})   // 下一轮事件循环立即执行
```

## console 对象

```javascript
console.log('普通日志')
console.error('错误输出')
console.warn('警告')
console.table([{ a: 1, b: 2 }])  // 表格形式
console.time('label')
// ... 操作 ...
console.timeEnd('label')          // 计时

// 带替换占位符
console.log('用户: %s, 年龄: %d', 'Alice', 25)
```

## 严格模式

Node.js 默认在模块级别启用严格模式（ES Modules 默认严格模式，CommonJS 建议手动开启）：

```javascript
'use strict'
// 严格模式下禁止的操作会抛出错误
```
