## 快速入门

```bash
# 检查版本
node -v

# 运行脚本
node app.js

# REPL 交互
node
```

## 推荐学习路径

1. 从 **[01-基础.md](./01-基础.md)** 了解 Node.js 基本概念
2. 掌握 **[02-模块系统.md](./02-模块系统.md)** 的模块导入导出
3. 学习 **[03-内置模块-文件与路径.md](./03-内置模块-文件与路径.md)** 和 **[04-内置模块-网络与流.md](./04-内置模块-网络与流.md)** 的核心模块
4. 深入 **[05-异步编程.md](./05-异步编程.md)** 理解事件驱动模型
5. 熟悉 **[06-进程与环境.md](./06-进程与环境.md)** 的进程管理
6. 学习 **[07-NPM与包管理.md](./07-NPM与包管理.md)** 的包管理
7. 掌握 **[08-错误处理与调试.md](./08-错误处理与调试.md)** 的调试方法
