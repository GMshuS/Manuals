# 使用 modelscope-hub 从 modelscope.cn 下载模型 【推荐】

## 官网地址：

https://modelscope.cn/home

## 安装 modelscope-hub 或者 modelscope

pip install modelscope-hub

或者 

pip install modelscope

## 模型下载使用示例：

**官网地址**
> https://hf-mirror.com/

**单模型文件下载**
> ms download Abiray/Qwen3.8-27B-Q4_K_M-GGUF Qwen3.8-27B-Q4_K_M.gguf --local-dir D:\llama.cpp\models -- 

**模型文件批量下载**
modelscope download --model unsloth/Qwen3.8-27B-GGUF --include "*Q4_K_M*" --local_dir D:\llama.cpp\models
